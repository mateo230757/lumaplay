# LumaPlay

**Tu universo de videojuegos.**

Página oficial: https://mateo230757.github.io/lumaplay/

## Descargar para Windows

Descarga el instalador gráfico:
https://github.com/mateo230757/lumaplay/releases/latest/download/LumaPlay_Setup.exe

El instalador es para Windows x64, incluye la aplicación y el runtime de .NET.
No pide al usuario instalar .NET Framework, .NET Runtime, C#, Visual Studio,
Build Tools ni un compilador. Después de descargar el instalador, no necesita
Internet para instalar LumaPlay.

## Desarrollo

Código fuente de la aplicación: Fuente/LumaPlay_Project/

- C# / Windows Forms sobre .NET 10.
- Publicación self-contained y single-file.
- Inno Setup 6 para el instalador visual.
- GitHub Actions compila y publica el instalador al actualizar main.

# LumaPlay

**Tu universo de videojuegos.**

Página oficial: https://mateo230757.github.io/lumaplay/

## Descargar para Windows

Descarga el instalador gráfico:
https://github.com/mateo230757/lumaplay/releases/latest/download/LumaPlay_Setup.exe

LumaPlay llega precompilada. El usuario no necesita C#, Visual Studio,
Build Tools ni un compilador. En Windows 10 22H2 y Windows 11, .NET Framework
4.8 o una versión superior compatible ya forma parte del sistema.

## Desarrollo

Código fuente: Fuente/LumaPlay_Project/

- C# / Windows Forms sobre .NET Framework 4.8.
- Compilación del ejecutable en GitHub Actions.
- Inno Setup 6 para el instalador visual.
- GitHub Actions publica el instalador al actualizar main.

# LumaPlay

Sitio web oficial de LumaPlay, publicado con GitHub Pages.

## Archivos del sitio
- `index.html`: página principal.
- `neon-drift.html`: minijuego arcade incluido.
- `favicon.svg`: icono del sitio.
- `LumaPlay_Windows_Package.zip`: paquete del proyecto para Windows.

## Publicación
GitHub Pages debe usar la rama `main` y la carpeta `/(root)`.

URL: https://mateo230757.github.io/lumaplay/

## Nota de instalación
El paquete ZIP incluye el proyecto y el asistente de instalación. Consulta el archivo LEEME incluido antes de instalar. El instalador necesita los componentes de compilación indicados en esa documentación.

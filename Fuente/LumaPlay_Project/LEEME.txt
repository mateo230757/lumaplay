LUMAPLAY 1.1.0 — WINDOWS x64
=============================

PARA LOS USUARIOS
-----------------
Descarga LumaPlay_Setup.exe desde:
https://github.com/mateo230757/lumaplay/releases/latest

Haz doble clic en el instalador. Verás un asistente gráfico con páginas
Siguiente / Atrás / Cancelar, licencia, carpeta de destino, opciones de
accesos directos, progreso y finalización.

No necesitas instalar C#, .NET Framework, .NET Runtime, Visual Studio,
Build Tools ni un compilador. El instalador lleva la aplicación ya compilada
y el runtime de .NET que necesita.

La instalación no descarga componentes de Internet. Después de descargar
LumaPlay_Setup.exe, puedes instalarla sin conexión.

REQUISITOS DEL USUARIO
---------------------
- Windows 10 22H2 o Windows 11.
- Procesador y sistema de 64 bits (x64).
- Espacio libre para la aplicación y el runtime incluido.

QUÉ INSTALA
-----------
- LumaPlay.exe, aplicación de escritorio.
- Acceso directo al menú Inicio.
- Acceso directo al Escritorio, opcional.
- Desinstalador de Windows.

Los ajustes y estadísticas se guardan en:
%LOCALAPPDATA%\LumaPlay

Al desinstalar, el instalador conserva esos datos personales para evitar
borrar perfiles o estadísticas sin permiso. Puedes eliminarlos manualmente
desde la carpeta indicada.

CONTENIDO
---------
- Biblioteca local para agregar y abrir juegos ya instalados.
- Inicio, Descubrir, Biblioteca, Logros, Ajustes y Acerca de.
- Neon Drift, arcade incluido.
- Perfil, color de acento, puntuación y datos locales.

LIMITACIONES
------------
LumaPlay es una biblioteca local. No incluye tienda, cuentas en la nube,
pagos, chat, multijugador ni descargas automáticas de juegos de terceros.
Añadir un juego registra la ubicación de su ejecutable; no copia ni instala
el juego.

COMPILAR COMO DESARROLLADOR
---------------------------
La compilación se realiza con .NET 10 SDK (solo para desarrolladores):
  .\Build.ps1
o ejecuta Compilar.bat.

Los usuarios de la aplicación no necesitan ninguna de esas herramientas.

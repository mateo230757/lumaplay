LUMAPLAY 1.1.0 — DETALLES TÉCNICOS
===================================

ARQUITECTURA
- Aplicación de escritorio C# / Windows Forms.
- Target: .NET Framework 4.8.
- Plataforma de distribución: Windows x64.
- Persistencia: JavaScriptSerializer en settings.json local.
- Instalador: Inno Setup 6, formato EXE con asistente gráfico.

DISTRIBUCIÓN
La aplicación se compila en GitHub Actions usando el compilador C# de un
runner Windows. El ejecutable LumaPlay.exe ya compilado se empaqueta dentro
de LumaPlay_Setup.exe. El PC del usuario nunca compila código.

El usuario final NO necesita:
- Instalar C#, Visual Studio o Build Tools.
- Tener csc.exe o un compilador.
- Compilar código en su propio PC.
- Descargar un runtime .NET aparte en Windows 10 22H2 o Windows 11.

.NET Framework 4.8 viene integrado en Windows 10 22H2; Windows 11 incluye
una versión posterior compatible con aplicaciones 4.8.

ASISTENTE
Inno Setup ofrece páginas gráficas de bienvenida, licencia, carpeta de destino,
tareas de accesos directos, confirmación, progreso y finalización, con botones
Siguiente, Atrás y Cancelar.

COMPILACIÓN
El compilador se usa únicamente en el entorno de desarrollo/CI, nunca durante
la instalación del usuario final.

NOTA
El instalador está dirigido a Windows 10 22H2 o Windows 11 de 64 bits.

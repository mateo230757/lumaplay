# LumaPlay para Windows

## Descarga

LumaPlay_Setup.exe:
https://github.com/mateo230757/lumaplay/releases/latest/download/LumaPlay_Setup.exe

## Instalación

1. Descarga y abre el instalador.
2. Avanza con Siguiente o vuelve con Atrás.
3. Acepta la licencia y elige la carpeta de instalación.
4. Selecciona si deseas un acceso directo en el Escritorio.
5. Pulsa Instalar y, al finalizar, puedes iniciar LumaPlay.

No necesitas instalar C#, Visual Studio, Build Tools ni un compilador.
Windows 10 22H2 ya incluye .NET Framework 4.8 y Windows 11 incluye una versión
posterior compatible. No hace falta descargar un runtime separado.

La instalación no descarga componentes de Internet después de descargar
LumaPlay_Setup.exe.

## Requisitos

- Windows 10 22H2 o Windows 11.
- Sistema de 64 bits (x64).

## Privacidad

LumaPlay guarda el perfil y las estadísticas en %LOCALAPPDATA%\LumaPlay.
Al desinstalar se elimina la aplicación, pero se conservan estos datos.
